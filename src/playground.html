Tuning playground

More Like This for a set of seeds, ranked by the scorer atlas serves, with any of its knobs moved. Every field starts at production's value; only what you change is sent, and every row re-ranks when you stop typing. Beside each title is its rank in production's row. Points are what each signal added to the score (spread × weight × value). The seeds and knobs are in the address, so a setup can be shared.

    Disabled: More Like This takes no viewing history today. The household tilt (den-core's order, tilt.liked/tilt.disliked) runs on browse rows only, and /index/suggest can only exclude titles.

    Not tunable yet

    • Per-axis facet weights (era, tone, pacing, ending, …): one w_facet covers all twelve axes, each weighted by its rarity. Needs a weight per axis in SimilarParams, applied in facet_agreement.
    • Facet filters (e.g. only tone=bleak): More Like This takes no constraint. Needs the constraint list /index/row already parses, applied as a candidate filter.
    • IMDb rating cutoff and IMDb votes floor: the scorer never reads ratings. atlas holds IMDb's daily ratings (Indexes::imdb_rating, Indexes::votes) when IMDB_RATINGS is on; needs them passed into the scorer (a trait like Authorship) as a filter or a term.
    • TMDB votes: atlas has no TMDB vote count any more (the store dropped it). Needs a source first; TMDB's own recommendations are merged by the client, not here.
    • I have watched: see above. Needs More Like This to take tilt.* and compose den-core's order over its row, as browse rows do, or an exclude list.
    • Critique floor (0.10) and the idf holds share (0.7): baked into corpus-wide aggregates built once at load. Needs those aggregates rebuilt (or memoised) per value.
    • Pool floor and spread percentiles (10th / 90th): literals in the scorer. Could become knobs.
